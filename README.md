# Leukemia Detection Using Hybrid Deep Learning

## Overview
This project presents a hybrid deep learning framework for classifying leukemia blood cell images using the ALL-IDB2 dataset. The proposed approach combines EfficientNetV2-S and ConvNeXt-Tiny to extract complementary features and improve classification performance.

The project includes:
- Data preprocessing
- Data augmentation
- Train/validation/test split
- Hybrid deep learning model
- Model training and evaluation
- Performance visualization
- Final trained model saving

## Dataset
- ALL-IDB2 Dataset
